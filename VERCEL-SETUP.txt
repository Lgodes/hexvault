HEXVAULT v166 — VERCEL READY

Deploy:
1. Upload/import this project to Vercel (or push it to GitHub and import the repo).
2. Framework Preset: Other.
3. No build command is required; index.html is served from the project root.
4. API routes are included under /api:
   /api/events
   /api/deck-import
   /api/judge
   /api/report-bug

Optional/required environment variables:
- OPENAI_API_KEY: required only for the server-backed Live Judge endpoint.
- The OpenAI API account must also have available API credit. ChatGPT subscriptions do not include API credit.
- RESEND_API_KEY: required for Settings → Support → Report a bug. Reports are delivered to hexvaultsupport@gmail.com.
- BUG_REPORT_FROM: optional verified sender, for example "HexVault Reports <reports@yourdomain.com>". Without it, the endpoint uses Resend's onboarding sender for initial testing.
- WIZARDS_MTR_URL: optional tournament-policy source for Live Judge.
- ARCANA_EVENTS_API_URL: optional approved JSON events provider.
- ARCANA_EVENTS_API_KEY: optional bearer token for that provider.

After changing environment variables, redeploy in Vercel.
If Judge fails, open Vercel Logs and inspect /api/judge. v145 reports missing credit, rejected keys, and rate limits separately instead of only saying "Judge unavailable".
HEXVAULT v146 — VERCEL SETUP

Required environment variable:
OPENAI_API_KEY = your OpenAI Platform API key

Optional:
OPENAI_VISION_MODEL = gpt-4o-mini

The scanner sends one compressed captured frame to /api/recognize-card. The endpoint reads the card name, language, set and collector number together, then verifies the result with Scryfall. Binder mode batches its pocket images into one recognition request.

HexVault searches the current Scryfall catalog and all multilingual printings. The optional offline database stores searchable card-name metadata on the device; HD artwork remains online and is cached as needed so the app does not become an enormous download.

After changing an environment variable, redeploy the production deployment. Then open the production URL directly, confirm Settings shows v166, and refresh/reinstall the PWA if an older cached version remains.
